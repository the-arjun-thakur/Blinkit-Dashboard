## 📊 Project Overview

This project presents an **interactive Power BI dashboard** analyzing sales data from **Blinkit – India's Last Minute Delivery App**.
The goal of this dashboard is to transform raw retail data into **meaningful business insights** using interactive visualizations and filters.

The dashboard helps analyze **sales performance, product categories, outlet characteristics, and customer ratings** to support better business decision-making.

## 📈 Dashboard Insights

### 1️⃣ Sales Analysis

* Total sales by **item fat content (Low Fat vs Regular)**
* Sales distribution across **different product categories**
* Identification of **top-performing items**

### 2️⃣ Outlet Performance

* Sales trends by **Outlet Establishment Year**
* Comparison of sales across **Outlet Sizes (Small, Medium, High)**
* Sales distribution across **Tier 1, Tier 2, and Tier 3 cities**

### 3️⃣ Store Type Comparison

Analysis of different outlet types:

* Supermarket Type 1
* Supermarket Type 2
* Supermarket Type 3
* Grocery Stores

Metrics compared:

* Total Sales
* Number of Items
* Average Rating
* Average Sales
* Item Visibility
